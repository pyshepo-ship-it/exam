# 📚 نظام إدارة الدروس الخصوصية

نظام شخصي لإدارة الدروس الخصوصية والاختبارات والتحصيل المالي.

## 🎯 المميزات

### 1. الصفوف والمواعيد
- إدارة الصفوف الدراسية (الرابع، الخامس، السادس...)
- تسجيل المجموعات مع المواعيد والأيام
- تحديد السعر الشهري لكل مجموعة

### 2. الطلاب
- تسجيل بيانات الطلاب (الاسم، الهاتف، الصف، المجموعة)
- البحث السريع عن الطلاب
- ربط كل طالب بمجموعة واحدة

### 3. التحصيل الشهري
- تسجيل الاستحقاقات الشهرية
- تسجيل المدفوعات
- حساب الأرصدة تلقائياً
- استحقاق شهري تلقائي لجميع الطلاب
- كشف حساب لكل طالب

### 4. الاختبارات
- 5 أنواع من الأسئلة:
  1. اختر الإجابة الصحيحة
  2. أكمل الجمل
  3. صح أو خطأ
  4. علل/فسر/اذكر أهمية
  5. صحح ما تحته خط
- تصدير الاختبارات إلى PDF
- حفظ الاختبارات للرجوع إليها لاحقاً

### 5. الحضور والغياب
- تسجيل حضور وغياب الطلاب لكل حصة
- تقارير نسب الحضور
- تسجيل سريع بنقرة واحدة

### 6. التقارير
- تقرير التحصيل المالي
- تقرير المجموعات
- تقرير الطلاب
- تقرير الاختبارات
- تقرير شهري شامل

### 7. الإعدادات
- تغيير كلمة المرور
- الوضع الليلي/النهاري
- إعدادات النظام

## 🛠️ التقنيات المستخدمة

- **Frontend**: Next.js 14 + TypeScript + Tailwind CSS
- **UI Components**: shadcn/ui
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Backend**: Supabase (PostgreSQL + Auth + Storage)
- **Hosting**: Vercel

## 📦 التثبيت

```bash
# تثبيت المكتبات
npm install

# إعداد ملف البيئة
cp .env.example .env.local
# قم بتعديل .env.local وإضافة بيانات Supabase

# تشغيل المشروع
npm run dev
```

## 🗄️ إعداد قاعدة البيانات

1. قم بإنشاء مشروع جديد في [Supabase](https://supabase.com)
2. انسخ `SUPABASE_URL` و `SUPABASE_ANON_KEY`
3. أضفها إلى ملف `.env.local`
4. شغل ملف `supabase/migrations/001_initial_schema.sql` في Supabase SQL Editor
